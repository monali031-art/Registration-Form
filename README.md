# Registration Form

## 📋 Project Overview
A simple and user-friendly registration form created using HTML and CSS.

## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- User registration form
- Name and personal information fields
- Form validation
- Submit functionality
- Success page after registration
- Clean and simple user interface
